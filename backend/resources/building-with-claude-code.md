## why this matters
i'm not the type of PM who throws requirements over the fence. AI coding tools mean i can prototype an idea, test it and sometimes ship it myself, which makes conversations with engineers much more concrete.

## what i've built
- **a customer portal redesign at Likvido**, done almost entirely by me with Claude Code - and i was the first PM there to make PRs myself (see "Product Manager @ Likvido")
- **three websites, built independently** with GitHub and Claude Code
- **two websites from scratch at iEDI** (see "Head of Marketing @ iEDI")
- **this chat** - see "This Chat"

## how i use AI day to day
Claude, Claude Code, Cursor and ChatGPT are a default part of my workflow: research, analysis, discovery, prototyping and technical exploration. i'm especially interested in where AI can make financial processes more proactive, instead of just automating the steps that already exist.
